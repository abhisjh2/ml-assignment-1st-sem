# AI/ML — 1st Semester, 1st Assignment

This folder contains the first-semester AI/ML assignment: an end-to-end machine-learning pipeline that predicts whether an online shopping session ends in a purchase (`Revenue`).

**Track:** A — scikit-learn. The project compares Logistic Regression, Decision Tree, Random Forest, Extra Trees, and Histogram Gradient Boosting using grid search and five-fold stratified cross-validation.

## Saved model results

These values are rounded from `output/model_comparison.csv`. Models are ranked by mean cross-validation average precision (AP).

| Model | CV AP (± SD) | Test AP | ROC-AUC | F1 |
|---|---:|---:|---:|---:|
| **Extra Trees (selected)** | 0.3849 ± 0.0277 | 0.3694 | 0.7695 | 0.4165 |
| Random Forest | 0.3834 ± 0.0218 | 0.3586 | 0.7683 | 0.3887 |
| Histogram Gradient Boosting | 0.3704 ± 0.0196 | 0.3719 | 0.7722 | 0.4150 |
| Logistic Regression | 0.3381 ± 0.0135 | 0.3256 | 0.7437 | 0.3796 |
| Decision Tree | 0.3267 ± 0.0137 | 0.3046 | 0.7088 | 0.3668 |

The model is selected using cross-validation AP on the training data. Gradient Boosting scores slightly higher on test AP, but selecting a model from the held-out test results would make that test set less independent.

`PageValues` is excluded from the main model because it may contain information recorded after a purchase decision. In a sensitivity check, including it raises cross-validation AP from about 0.384 to about 0.754, which is a strong sign that it can leak the target.

## Reproduce the analysis

The `.ipynb` notebook is currently missing from the working tree, so the commands below will work after it is restored. From this folder, create and activate an environment, then install the dependencies:

From this folder, create and activate an environment, then install the dependencies:

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Execute the notebook and regenerate its report outputs:

```bash
jupyter nbconvert --execute --to notebook --inplace assignment1_pipeline.ipynb
python make_pdfs.py
```

The notebook uses random seed 42 and keeps imputing, scaling, and category encoding inside the model pipeline. Rerun it before rebuilding the CSV, summary, or short report so those generated files come from the same run.

The printable notebook PDF, short report PDF, and Prayogshala screenshot are also currently absent from the working tree. If you add the lab screenshot back and want the report builder to include it, save it as `figures/virtual_lab_screenshot.png` before running `python make_pdfs.py`.
